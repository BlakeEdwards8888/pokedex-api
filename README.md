# Pokedex API

A RESTful API built with C# and ASP.NET Core for storing, retrieving, updating, and deleting Pokémon data

Demo: https://dexappsvc-hvhqevbjdrhue5cc.canadacentral-01.azurewebsites.net/swagger/index.html

## Overview

Pokédex API is a backend application that provides a RESTful interface for managing Pokémon data. The project was my first solo API project and was built to develop a practical understanding of backend development, REST architecture, HTTP methods, and CRUD operations using C# and ASP.NET Core.

The API provides endpoints for creating and managing Pokémon records, as well as retrieving individual Pokémon or collections of Pokémon.

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- Swagger
- Git
- Azure

## Features

- Full CRUD operations
- Entity Framework Core data persistence
- Swagger documentation
- Asynchronous API operations
